# Code of Conduct

This project follows the [Contributor Covenant, version 2.1][cc].
By participating in this project (issues, pull requests, discussions),
you agree to abide by its terms.

## Scope

This Code of Conduct applies within all project spaces, and also when
an individual is officially representing the project in public spaces.

## Reporting

To report a concern, contact the maintainer at
&lt;david@villacis.net&gt;. All reports will be handled with discretion.
The maintainer is responsible for clarifying and enforcing the
standards described in the upstream Contributor Covenant text linked
above, and may take any action they deem appropriate (including a
warning or ban) in response to behaviour deemed inappropriate.

[cc]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
